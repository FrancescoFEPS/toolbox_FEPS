Nameplates generator

Make a PowerPoint of table nameplates in under a minute: one slide per person, all with the same design.

How it works: you give this page the logos and a list of names. It copies the nameplate design once for each name and gives you back a ready-to-print PowerPoint file.

1

Add your logos

The FEPS logo is already on the nameplate. If other organisations take part in your event, add their logos here (PNG or JPG, up to 5). They are placed after the FEPS logo, from left to right, in the order you add them. A PNG with a transparent background looks best.

    Loading the nameplate design…

    Use a different nameplate design

    Only needed if you have your own PowerPoint design. Choose a .pptx file whose first slide is a finished nameplate with any name written on it. Other slides in the file are ignored.

    Tip: the name on that slide is replaced in every text box, so keep other text, such as an event title, out of text boxes on that slide. Every picture on the slide is treated as a logo.

    2

    Paste your names

    Type or paste one name per line, then press Enter after each one.

    Optional: only the columns “Name” and “Last name” are used. The names fill the box below, where you can still edit them.

    Titles and organisations are ignored: “* Ania Skrzypek, Director, FEPS” becomes “Ania Skrzypek”. Names are copied exactly as typed.

    How do I paste names from Excel or Google Sheets?

    Put the names in one column, select the cells, copy them (Cmd/Ctrl + C), click in the box above and paste (Cmd/Ctrl + V). Each cell becomes one line.

    If your design shows surnames in capitals, type them that way (for example “Ania SKRZYPEK”): the page does not change capitals for you.

    3

    Create your file

    The button turns on as soon as you have pasted at least one name.

    Your file is ready. What now?

    1. Open Nameplates_final.pptx from your Downloads folder.
    2. Look through the slides to check every name.
    3. Print on thick paper: one slide per page, landscape, at 100% size.
    4. Fold each sheet in half across the middle, so one name faces each side of the table.

      Questions

      Are my names or my file uploaded anywhere?

      No. Everything happens inside your browser, on your computer. Nothing is sent or stored online.

      A name is too long and does not fit on the card

      Open the downloaded file and make the font a little smaller on that slide, or shorten the name here and create the file again.

      I clicked “Create nameplates” but nothing downloaded

      Check your Downloads folder first. If it is not there, your browser may have blocked the download: allow it in the address bar, or try another browser.

      Can I remove or replace a logo that is already in my template?

      Yes, but do it in PowerPoint, before using the template here: right-click the logo, choose “Change Picture” (or press Delete to remove it). Do it for both copies, the upright one and the upside-down one.

      Can I edit the slides afterwards?

      Yes. The result is a normal PowerPoint file, so you can change anything before printing.

      I get a message saying my file cannot be read

      Make sure it is a PowerPoint file ending in .pptx (not .ppt, .key or a PDF). In PowerPoint, use File > Save As and choose “PowerPoint Presentation (.pptx)”.

      Everything runs in your browser: your template and your names never leave your computer.
