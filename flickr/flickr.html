Flickr link maker

Paste a link and its title, and get the code of a link with the 🔗 emoji, ready to paste in a Flickr description.

How it works: you type the address and the text of the link. The page writes the code for you, always in the same way, and you copy it.

1

Give the link

The address is copied exactly as you type it. If it starts without https://, the page adds it.

2

Copy the code

Then paste it in the description of your photo on Flickr.

Your link will appear here once you fill in the two boxes.

This is how the link will look. Click it to check that it opens the right page.

Questions

What does the code look like?

It is the emoji, then the link: 🔗 followed by a link whose text is the one you typed. The link opens with rel="noreferrer nofollow", as in your example.

My address ends with two slashes (//)

The page does not change the address you type, so check it before copying: a double slash at the end can sometimes lead to an error page.

Does it work for several links?

Make the code once per link and paste them one under the other in the description.

Is my text sent anywhere?

No. Everything is made inside your browser and nothing is sent online.

Everything runs in your browser: what you type never leaves your computer.
