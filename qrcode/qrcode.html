    Questions

    Is my link or logo uploaded anywhere?

    No. The code is made inside your browser, on your computer. Nothing is sent online.

    Does the logo stop the code from working?

    No, as long as it stays small. The code is made with the highest level of error correction when there is a logo, so it can still be read with the middle covered. Keep the logo at 25% or less, and always scan the result with your phone before using it.

    The page says the link is too long

    A QR code with a logo can hold about 1,000 characters at most, and long links make a dense code that is hard to scan. Use a shorter link.

    The page warns about low contrast

    Phones read dark code on a light background best. Choose a much darker code colour than the background, and avoid light code on a dark background.

    Will the code stop working one day?

    The code contains the link itself and nothing else, so it works as long as the page at that link exists. It does not depend on this tool.

    Everything runs in your browser: your link and your logo never leave your computer.
