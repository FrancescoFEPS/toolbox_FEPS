Registration list

Turn the registrations exported from the website into the printable signature list.

How it works: you upload the Excel file and/or paste names, remove the people you do not want, check the event details, and the page fills in the Word document for you: everyone sorted by last name, followed by 2 blank pages for guests who did not register online.

1

Add the people

Upload the Excel file exported from the website (.xlsx or .csv). Everybody in the file is listed on the right, where you can remove anyone.

The file needs a column “Name” (first name) and a column “Last name” (or “Surname”). If first and last name are in one column, that is fine too. “Organisation” is optional: it can also hold the job title, and if there is none the cell stays blank.

Or add names by hand

One person per line, for example “Ania Skrzypek, FEPS”. You can also copy cells from Excel (Name, Last name, Organisation).

2

Event details

These replace the event name, date and place at the top of the document.

3

Add logos (optional)

The FEPS logo is already in the document header. Add the logos of other organisations (PNG or JPG, up to 5): they are placed next to it, a bit smaller, from left to right, in the order you add them.

    4

    Create your document

    The button turns on once there is at least one person in the list.

    Loading the Word template…

    Your document is ready. What now?

    1. Open Registration_List.docx from your Downloads folder.
    2. Check the header (event name, date, location, logos) and the list.
    3. Print it: the last 2 pages are blank, for guests who did not register online.

    People in the list

      Sorted by last name, A to Z. Use “Remove” to take someone out. Two blank pages are added at the end of the document.

      Questions

      Which columns of the Excel file are used?

      Name (first name) and Last name (or Surname), or a single column with the full name. Organisation is optional (it may also contain the job title). Everything else is ignored. The column titles must be on the first row of the first sheet.

      First and last name are in the same column

      The page splits them. If the last name is written in capitals (“Andreas SCHIEDER”), everything in capitals is the last name; otherwise the last word is. Check the list on the right, and use “Remove” and add the person by hand if one is wrong.

      How do I remove someone?

      Click “Remove” next to their name in the list on the right. To start again, reload the page.

      In what order are the people listed?

      By last name, from A to Z (accents are ignored), then by first name.

      What are the 2 blank pages at the end for?

      For guests who did not register online: they can write their name, organisation and signature by hand. Each blank page has 12 lines.

      Can I edit the Word document afterwards?

      Yes. It is a normal Word file, so you can change anything before printing, including the event name, date and location in the header.

      A long organisation name does not fit

      The row simply gets taller to show the whole name, so nothing is cut off.

      The page says the Word template could not be loaded

      Open the page from the website link, not from a downloaded copy of the file, then refresh the page.

      Is the Excel file uploaded anywhere?

      No. Everything happens inside your browser, on your computer. As the file contains personal data, keep the Word document you create in a safe place and delete it when you no longer need it.
