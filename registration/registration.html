Registration list

Turn the registrations exported from the website into the printable signature list.

How it works: you upload the Excel file, check the event details, and the page fills in the Word document for you: only people whose status is “Allow” (or who have no status), sorted by last name, followed by 2 blank pages for guests who did not register online.

1

Upload the registrations

Choose the Excel file you exported from the website (.xlsx or .csv). Only the Name, Last name and Organisation columns are used, and only for rows whose STATUS is “Allow” or empty (a file without a STATUS column is fine too).

      People in the list

        Questions

        Which columns of the Excel file are used?

        Name, Last name and Organisation are required, and STATUS is optional. Everything else (email, job title, newsletter…) is ignored. The column titles must keep these names, on the first row of the first sheet.

        Why is someone missing from the list?

        People whose STATUS is “Allow” or empty are kept, and so is everybody if the file has no STATUS column. Anyone with another status is left out, and the “Who was left out?” menu in step 1 shows who. To include someone, change their status to “Allow” (or clear it) and upload the file again.

        In what order are the people listed?

        By last name, from A to Z (accents are ignored), then by first name.

        What are the 2 blank pages at the end for?

        For guests who did not register online: they can write their name, organisation and signature by hand. Each blank page has 12 lines.

        Can I edit the Word document afterwards?

        Yes. It is a normal Word file, so you can change anything before printing, including the event name, date and location in the header.

        A long organisation name does not fit

        The row simply gets taller to show the whole name, so nothing is cut off.

        The page says the Word template could not be loaded

        Open the page from the website link, not from a downloaded copy of the file, then refresh the page.

        Is the Excel file uploaded anywhere?

        No. Everything happens inside your browser, on your computer. As the file contains personal data, keep the Word document you create in a safe place and delete it when you no longer need it.
