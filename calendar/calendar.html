Add to calendar

Make an “Add to calendar” file and links for an invitation or a newsletter.

How it works: you describe the event once. The page gives you a calendar file (.ics), direct links for Google Calendar and Outlook, and a ready-to-paste piece of HTML for Sarbacane.

1

Describe the event

If you leave the end empty, the event lasts one hour.

2

Get the calendar file

The .ics file opens in Apple Calendar, Outlook on a computer and most phones. The Google and Outlook web links are on the right.

3

Use it in a Sarbacane newsletter

Choose the links to put in the newsletter, then copy the code and paste it in a code block of Sarbacane.

Fill in the title and the start date to see your links here.

Links

    Click “Open” to test a link before you use it.

    Questions

    Which link should I put in a newsletter?

    The Google Calendar and Outlook links work directly, nothing to upload. The .ics file works for Apple Calendar and Outlook on a computer, but it must be put online first, because a newsletter cannot carry a file by itself.

    Which time zone should I choose?

    The one where the event takes place. Each person then sees the event at the right time in their own calendar. Brussels, Paris, Berlin, Rome and Madrid share the same time.

    The Outlook link does not open my work calendar

    There are two Outlook links: one for work or school accounts (Microsoft 365) and one for personal accounts (Outlook.com, Hotmail). Use the one that matches the account.

    Can I add a reminder or invite people?

    Not here. The person who adds the event can set their own reminder in their calendar.

    Is my text sent anywhere?

    No. Everything is made inside your browser and nothing is sent online.

    Everything runs in your browser: what you type never leaves your computer.
