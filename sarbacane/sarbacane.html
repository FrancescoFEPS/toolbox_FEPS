Sarbacane code cleaner

Paste the raw HTML code of a Sarbacane newsletter and get the cleaned-up code back.

How it works: the page makes 4 small, fixed changes to the code. It does not change your text or your images.

1

Paste your code

Copy the raw HTML code of your Sarbacane newsletter and paste it here.

2

Clean it

    What exactly does it change?
    • The <body> becomes a <div> with a transparent background.
    • The background of the main table changes from #f6f1f1 to white.
    • The closing </body></html> becomes </div></html>.
    • A style line for .singlePostContent (background #f6f1f1) is added at the top of the styles.
    3

    Copy the result

    Everything runs in your browser: your code is never uploaded anywhere.
