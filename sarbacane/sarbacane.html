    • The closing </body></html> becomes </div></html>.

    Questions

    Where do I find the raw HTML code of my newsletter?

    In Sarbacane, use the option that shows the HTML code of your campaign, then select all of it and copy it. Paste it in step 1 exactly as it is, from the very beginning to the very end.

    It says “Nothing was changed”

    The page looks for four exact pieces of code and found none of them. Check that you pasted the complete raw code of a Sarbacane newsletter, not just a part of it or the visible text.

    It says only 2 or 3 of the 4 changes were applied

    Some pieces of code were not in your newsletter, so those changes were skipped. The list under the button shows which ones were applied (✓) and which were not found (–). Check the result before using it.

    Does it change my text or my images?

    No. It only makes the four changes listed under “What exactly does it change?”. Everything else stays as it is.

    What do I do with the cleaned code?

    Use it in place of the original code, wherever you would have pasted the original. The “Copy the cleaned code” button copies all of it at once.

    Is my code uploaded anywhere?

    No. Everything happens inside your browser and nothing is sent online.

    Everything runs in your browser: your code is never uploaded anywhere.
