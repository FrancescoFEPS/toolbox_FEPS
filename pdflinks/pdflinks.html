PDF links extractor

Choose a PDF and get all the links it contains, complete, even when they are cut over two lines on the page.

How it works: a clickable link in a PDF is stored whole in the file, whatever the way it is printed on the page. The page reads these links and lists them, ready to copy.

    Questions

    Why are the links complete here, when they are cut when I copy the text?

    When you copy text from a PDF, you get the text as it is printed, line by line. But a clickable link also holds its full address inside the file, in one piece. This page reads that address, so the way the text is cut over lines does not matter.

    The page says no clickable link was found

    The addresses in your PDF are probably only text, not real links. Click on one in the PDF: if nothing opens, it is plain text. This tool cannot read them.

    The text of the link is not shown

    Only the address is listed, with the page where it is. The words that carry the link (for example “read more”) are not read. Use the page number to find them.

    Some links are missing

    Links that go to another page of the same PDF are left out on purpose, as they are not web addresses. Links drawn inside an image are found only if the PDF makes them clickable.

    The page says the PDF could not be read

    The file may be protected with a password, or damaged. Open it, remove the protection (or print it to a new PDF), and try again.

    Is my PDF uploaded anywhere?

    No. Everything happens inside your browser, on your computer.
